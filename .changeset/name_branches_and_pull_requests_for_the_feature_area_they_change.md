# Name branches and pull requests for the feature area they change

Agents titled pull requests `proposal: …` and named branches `proposal/…`, which says only that the work starts with a proposal. The process contract, the commit-discipline rule, and the `writing-a-proposal` skill now have agents title a pull request as a Scoped Commits subject for the feature area it changes and name its branch for the same area, such as `exports: queue report exports` on `export-queue`.
