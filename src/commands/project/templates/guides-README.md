# Guides

This directory holds reader-facing explanations of how to use the project.

Name each file `<slug>.md`, using a unique kebab-case slug. Required frontmatter is `id: guide.<slug>` and `title`. Guides have no `status` lifecycle; revise them when the behavior they explain changes. Link the current sources a guide explains, such as API reference or feature files, with ordinary Markdown links. Historical context, when useful, is a sentence of prose.
